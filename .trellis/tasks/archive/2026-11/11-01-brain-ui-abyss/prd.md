# 脑图深海粒子版 UI 改造

> 存档约定：每次问题探讨都存档为 task——记录「遇到了什么问题 / 怎么解决的 / 什么时候干的」。本文件即本次探讨与实施的存档。

## 问题存档

- **时间**：2026-11-01
- **遇到的问题**：当前 `/brain` 页是"纸本标本图谱"风格（大脑剖面 + 宋体质感），辨识度高但关系表达弱：图最多展示保持率前 10 条记忆，连线仅为文本 2/3-gram 重合的临时推断，无法看出"这条记忆和谁有关、为什么有关"，也缺少现代感与交互性。
- **探讨的方案**：做了三版可交互概念稿——A 关系探索（克制清晰）、B 深海神经舱（深蓝全息 + 漂浮粒子）、C 蓝潮记忆航行（明亮蓝 + 角色陪伴），以及 B×C 融合版。
- **结论**：用户选定 **B 深海粒子**为正式方向；A、C 存档于仓库根 `mockup-atlas-{a,c}.html`，后续作为脑图个性化皮肤的拓展储备。融合版探索证明角色陪伴元素可用，但本期不引入用户供图（授权未定），人格徽标用纯 SVG/CSS 表达。

## Goal

将 `/brain` 心智图谱页从"纸本标本图谱"改造为 B 概念「深海神经舱」方向：深色全息画布 + 漂浮粒子 + 可探索的记忆关联图。关系表达升级为第一公民，同时保留全部现有功能。

- `/brain/api/state` 返回 notes（含 kind/actor/sessionId/importance/retention/hits/fading）+ emotion + persona + stats；**无真实关系边数据**。

## Requirements

- **R1 视觉**：深海主题贯穿整页（画布、侧栏、卡片、数据区页签统一暗色），霓虹青蓝高亮；保留"人格内核常亮、情绪独立流动"的概念表达；尊重 `prefers-reduced-motion`（粒子默认关）。
- **R2 关系表达**：保留文本相似推断连线并升级——选中节点时相邻连线高亮、无关元素淡出；新增"同一会话 / 同一发言人"弱关系（与相似线样式区分）；边总量设上限防糊；图例明示「推断关联，非因果事实」。
- **R3 详情面板新增「关联记忆」区**：列出相邻记忆 + 推断理由（共享主题词 / 同一会话 / 同一发言人），点击跳转选中；与现有编辑区、衰减曲线共存。
- **R4 画布交互**：拖拽平移、缩放按钮、复位视图；节点上限从 10 提至 ~30（仍按保持率+重要度排序）；标签沿用"hover/focus/selected 才显示"策略防拥挤；检索命中继续高亮相关边。
- **R5 功能不回归**：记忆库/画像/人设/备份四页签、记忆 CRUD+强化、检索模拟、15s 刷新保留编辑草稿、token 透传全部保留。
- **R6 人格与情绪**：作为非记忆元素呈现（中央人格徽标 + 情绪节点），不混为记忆节点；人格表现用纯 SVG/CSS，不引入参考图素材。

## Acceptance Criteria

- [ ] AC1 (R1,R4)：桌面与窄屏整页深海主题且无横向溢出；粒子可开关且偏好记忆，`prefers-reduced-motion` 下默认关。
- [ ] AC2 (R2,R3)：选中任一记忆节点，相邻连线高亮 + 无关元素淡出；详情面板列出相邻记忆及推断理由，点击邻居切换选中；相似 / 同会话 / 同发言人三类关系在图例中可区分。
- [ ] AC3 (R4)：画布可拖拽、缩放并一键复位；~30 条记忆时概览不重叠拥挤；检索模拟器命中仍高亮相关边。
- [ ] AC4 (R5)：页面脚本语法测试、token 透传、人设草稿保护等 `npm test` 全绿（含新增关系计算用例）；`npm run typecheck`、`npm run build` 通过；CRUD/强化/15s 刷新编辑保护无回归。

## Resolution（2026-11-01）

**遇到了什么问题**：以概念 B「深海粒子」为基础改造 `/brain`，先后经历"贴皮不像概念""节点太滑/水珠球丑/点击慢/拥挤堆叠""与 v2.html 差距大"多轮反馈，最终按 B 骨架整段重写 CSS/markup 后，用户仍认为效果不行——根因是 B 本身不具备"类脑结构"，情绪与人格也没进入关联网络。

**怎么解决的**：本任务以**被取代**收尾。期间产出的可复用部分——`computeRelations()`/`relationWhy()`（话题/会话/发言人三类推断关系 + 测试）、检查器关联区、内联立绘 `PERSONA_IMG`/`PERSONA_BANNER`、jsdom 冒烟脚本（`/tmp/brain-stub`）——作为起点并入新任务 `11-01-brain-ui-cortex`（以概念 ①「鲸脑皮层」重构）。B 版代码未单独提交，随新任务一起落地。

**Key Decisions**：不再迭代 B；A/B/C 概念稿（`mockup-atlas-*`）保留为个性化素材；力导向、粒子、平移缩放将在新任务中移除（固定脑区布局）。

**验证**：交接时工作区 `npm test` 76/76、typecheck、build 通过。

**后续优化方向**：见 `11-01-brain-ui-cortex`；B 的深海粒子视觉可作为皮肤候选。

**什么时候干的**：2026-11-01。
