# 记忆阶段感与前后冲突机制探讨

## 问题（2026-11-07 用户提出）

情景记忆有没有前后关联性？会不会前后冲突？以恋人线为例：库里同时有「已进入亲密关系」「已发生多次」等事实——大肥鱼的行为自我定位会不会停留在早期阶段（初次害羞），而没有推进到「已自然相处、可主动」？阶段感由什么决定？

## 结论：无显式阶段变量，「阶段感」由四层注入通道涌现

系统没有 relationship-state 概念。实际「她觉得自己处在哪个阶段」= 四类通道的加权合成：

| 通道 | 更新语义 | 阶段滞后风险 |
|---|---|---|
| 画像 `[画像]`（每轮置顶注入） | 单字段滚动重写 | 无——天然最新覆盖，**最强阶段锚** |
| 会话脉络 digest（每轮注入） | 滚动重写 | 无 |
| 语义记忆 | 巩固压缩 + 入库判重 merge | 低——merge 把新阶段事实写进旧摘要 |
| 态度 `对X：` | 同对象原位替换 | 无——只保留最新立场 |
| **情景记忆** | **append-only 冻结快照** | **有——唯一滞留旧阶段的层** |

裁决顺序：persona 给性格基线 → 画像给关系定位 → 态度给行为规则 → 情景给具体先例。

## 情景层的冲突面（真实数据佐证）

demo 恋人线 episodic 是兼容递进的时间切片（确认关系→磨合→常态化），尚无互相矛盾的条。会打架的形态是「后取代前」型（如「初次害羞」vs「已自然」）：同池竞争、同屏注入，仅靠 `[x天前记]` 前缀让聊天模型自行排序，**无「新取代旧」的显式关系**。

## 会卡/不会卡的机制

**防滞后（现状有效）**：画像+脉络每轮必注当前态；consolidate() 把老 episodic 吸进语义并 absorbedAt 退池——里程碑最终只剩「语义版当前结论」。

**会滞留的三个具体机制**：
1. **强化回路自我维持**：亲密场景中旧阶段条相关性高→命中→reinforce→保持率回涨→持续占 topK。衰减保护不了被高频场景反复点亮的过时快照。
2. **mergeIndex 是软约定**：措辞差异大的同主题更新（cos<0.9 判重不命中），LLM 也未必指 merge——旧条原样存活。
3. **里程碑条滞留窗口**：i5 事件条在巩固吸收条件（≥1天+≥4条同会话）达成前持续占检索位；低频会话滞留更久。

**额外发现**：demo 画像写「明确说喜欢她害羞的样子」——害羞被记成对方期望特质，「退回害羞」部分是画像强化的行为而非纯阶段回退。

## 可选优化方向（未实施，探讨记录）

1. **supersede 边**：入库时同主题更新检测（比判重宽、比 merge 硬），命中写 `supersededBy` + 旧条退池/降权
2. **阶段事实不入 episodic**：蒸馏规则「关系阶段/亲密度结论归画像/attitude 素材，不作独立事件」
3. **注入端时序提示**：被更新条目加 `↳更新于x天前` 后缀（轻量展示层）
4. 显式 relationship-state 字段——与画像/attitude 职责重叠，不建议

## Resolution（2026-11-07）

- **问题**：用户担心情景记忆无阶段概念会导致角色行为卡在关系早期。
- **结论**：阶段感由「最新覆盖」通道（画像/脉络/语义/态度）主导，情景层是唯一会滞留旧快照的 append-only 层；滞留的三个具体机制是强化回路、merge 软约定、里程碑吸收窗口。线上 demo 恋人线数据显示当前机制推进良好、尚无真实冲突。
- **怎么解决**：本次为机制探讨，未改代码。若需硬保证优先做 supersede 边（方向 1）或生产端不入规则（方向 2）。
- **验证**：对照线上 brain state 实证——画像文本反映当前阶段、语义/态度为最新立场、episodic 为兼容递进切片。
