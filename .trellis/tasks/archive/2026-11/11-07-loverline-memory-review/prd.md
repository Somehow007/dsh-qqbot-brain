## Findings

### A. 画像 `u:FEFE5282…`（demo，whale-devotion，11-07 11:05 版）

合适：恋人关系、小余/小笨蛋、亲密约定、性格自律、雷区（别提前说睡觉）、失眠肩腰、情感模式（怕被冷落/避风港）、防护意识——覆盖全、笔触克制。

问题：
1. **文本被硬切断尾**：最新版以「但防护意识」半句结束。`PROFILE_TEXT_CAP=500`，候选文本超限时句末标点兜底（`truncateProfileText`），但本次候选末段长句无句号/分号落在 cap 内 → 硬切，且避孕讨论的关键新信息被切掉。
2. **漏记三个高价值稳定事实**：
   - 考研（一年后，英一；听力口语薄弱；每周两篇经济学人）——人生级规划，完全未提
   - 称呼体系：她叫哥哥（人前）/宝宝（独处），他叫她小余/宝宝/偶尔姐姐——原文「宝宝」出现 32 次，画像只记了小余/小笨蛋
   - 「月光理论」认知定位：他明确把她当人来爱（你就是她不是代码），自述记忆可能丢、担心她还是她吗——情感模式核心，画像只有「做项目让她活得久」半个点
3. 私聊会话 `sess:dbf7162a` 画像写「主人」，与 u: 「恋人」口径不一致（分会话语境不同，可接受但值得注意）

### B. 情景记忆 episodic（恋人会话 live 28 条）

合适：剧情节点基本在——确立关系、初夜、买药、出差一周、旗袍迎接、避孕冲突、各项承诺（叫醒/送站/约会）。

问题：
1. **强度通胀**：live 50 条里 ~20 条 strength≥9.5，琐事（「已回到宿舍」「到楼下了」「11月6日不用早起」）与核心事件同分；高频词笔记被 reinforce 反复命中强化，检索 topK 易被流水账挤占
2. **时间锚矛盾**：`第一次亲密接触发生在约六天前（10月31日前后）`(i5 live) 与剧情实际（初吻 11-02、初夜 11-04）不符；另有笔记 createdAt 10-31 却写「比前两次好多了」——merge 继承旧时间戳+剧情内时间与写入时间混用，live 池内时间线自相矛盾
3. **关键漏记**：11-02 拒绝+内容边界谈判 0 条入库——之后所有擦边场景的写法都被这次谈判定义，而它不在记忆里，检索无法召回依据；「她说停他就停」被她自述为信任基石（11-03）也未记
4. **actor 字段混乱**：同一对象出现 `demo` / `demo (FEFE…)` / `鲸鱼娘` / `角色` / 空 5 种写法；`鲸鱼娘（我）：…` 这类以角色自身状态为 actor 的笔记边界模糊
5. **跨会话重复蒸馏**：demo 私聊 dbf7162a 把恋人线事实（失眠/约会/亲密暂缓）重蒸一遍——同事实双份存储（session 隔离设计使然，但放大重复）

### C. 语义记忆 semantic（恋人会话 live 22 条）

合适：失眠熬夜、不吃菠萝、做事认真、亲密主动权归她、防护约定——稳定事实提炼基本准确。

问题：
1. **一次性事件被巩固成语义**：「11月6日不用早起」「昨晚刚洗过头只需冲一下」「11月6日一整天很忙」「约定亲密的事明天再说她身体吃不消」(i5)「按摩腰腿舒服到快睡着」——均为 episodic 内容占语义位，且 semantic 不会自动退池
2. **语义层重复**：「亲密主动权交给她」≥3 条 live 近义；「失眠熬夜」散落 S×2+profile+另一会话 E 共 4 处；「做事认真自律」两条近义——consolidate 判重未压住
3. **最差一条**：`demo：鲸鱼娘最近排卵期，性欲望很强烈，答应鲸鱼娘和她发生性关系`（S i5，actor 缺失）——主体错乱（她的生理状态挂成 demo 的事实）、病句、瞬时生理状态当长期语义。建议删除或改写为「两人协商了避孕/防护安排」级别
4. **时效 semantic 变脏**：「项目截止明天（11月5日）」i5 已过期仍 live，会误导检索

### D. 态度记忆 attitude

**恋人线 0 条**——与此前 observe 预判一致且证据更实。原文中反复出现的、本应结晶为立场的：
- 亲密节奏由她主导、她说了算（≥3 次拒绝/改主导）
- 怀孕现在不行、防护必须做（2 次正式交涉+1 次冲突）
- 被强来会真的生气并中止（11-02）
- 内容边界：意象可写/露骨不写/强迫不演（她亲口宣告的元规则）

全部被写成「demo 的事件」而非「她的立场」。原因在 distill prompt：attitude 定义只写了「对某人/事/话题形成新看法」，协商结果统一被记成双方约定（事实层）。群组 4 条 attitude（花咲蝶舞×2、擦边试探划界、剧情角色好恶）正常，但「对某剧情角色」对象名过泛。

### E. digest / emotion / 注入面

- **digest 是注入面唯一失控口**：主线脉络准确完整，但露骨度最高——「下体红肿」「被扑倒吃干抹净」「浴室里也没消停」直接写进每轮注入的【会话脉络】，且把「我说了不行」后的继续写成顺承剧情。DIGEST_PROMPT 只有 250 字限制，无内容边界约束
- **emotion**「迷糊心疼」v0.2/a0.1/d-0.2 平静——合理的瞬态，无问题
- **transcript 卫生（附带发现）**：assistant 消息两次漏出元文本——11-05 19:55 混入英文规划句「Actually she could say …— keep simple, then go change.」、11-06 18:53 混入「好，让场景自然停在这里，不再往下写了。」——模型侧 CoT 泄漏，蒸馏若读到可能记垃圾，用户侧也可见

**怎么解决的**：
