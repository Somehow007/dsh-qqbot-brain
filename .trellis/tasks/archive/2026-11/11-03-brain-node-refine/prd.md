# 脑图节点视觉收敛：小号化+统一神经元语言

## Goal

脑图节点偏大且风格不统一：情绪是实心大色点（金/橙/粉高饱和），与人格/记忆的「深色底+细色环+小核」神经元语言不搭。整体缩半径并将情绪节点改为同款结构。

## Requirements

- 情绪 r 5–11 → 4–8，实心盘 → 细环(stroke=e.color) + 小核(r*.5) + 8% 淡色底 + halo
- 人格六边形 r 11–16.4 → 9–13.2；记忆 r 7–8.2 → 6–7.1
- 标签字号 11.5/12.5 → 11/12；`layoutSlots` 占位 box 不动，节点位置不变留白更松
- `mood-ring` 心跳、`.emo.empty` 45% 透明度、图例色相映射保持不变

## Acceptance Criteria

- [x] 三类节点同一套「环+核+晕」视觉语言
- [x] 视觉重量明显下降，色相仍可区分情绪桶
- [x] `npm test` 通过

## Resolution（2026-11-03）

- **遇到了什么问题**：情绪节点 r5–11 实心高饱和圆盘在细线条深蓝解剖图上喧宾夺主；三类节点两套画法。
- **怎么解决的**：`page.html` render() 三类节点半径公式整体下调，emo 节点从实心 `circle` 改为 `ring`(stroke 着色+fill-opacity:.08)+`core`(r*.5) 结构，复用 `.node .ring` CSS；halo/cap 偏移随半径等比缩小。
- **后续优化方向**：若嫌空情绪桶（empty 45%）仍显眼可再降到 .35；情绪色相如需更冷可整体降饱和。
- **什么时候干的**：2026-11-03，紧随 footer 覆盖修复之后。
- **Key Decisions**：不动 layoutSlots box —— 占位不变则节点坐标零漂移，纯视觉缩圈即得更多留白；情绪色保留原色（图例一致性），靠形态减重而非改色。
- **验证结论**：`npm test` 121/121 通过；静态预览复核。
