# 画像内容边界

## Goal

画像只承载长期维护的「这个人是什么样的」，不被时效性信息污染。

## 遇到了什么问题

用户反馈：画像里出现了「最近课表」这类本该进记忆（memories）的时效内容。根因：蒸馏 prompt 对 profiles 字段只规定了格式与字数，**没有定义"什么才配进画像"**——LLM 默认把了解到的用户信息都往里写。

## 怎么解决的

prompt 补边界（commit `1e85bdf`）：
- 主蒸馏 PROMPT 新增规则：画像只写长期成立的判断（性格特质/身份背景/关系定位/稳定偏好雷区）；时效性信息（最近课表、当下在忙什么、一次性安排、刚发生的小事）写进 memories 不进画像。
- CONSOLIDATE_PROMPT 的 profiles 描述同步加「长期成立的性格/关系/稳定偏好，时效信息留给语义记忆」。

## 验证

62/62 测试（含 prompt 边界断言）、typecheck、build；dist 已同步云服务器并重启生效。
注意：prompt 约束是软性的，存量画像里已有的时效内容随下次修订自然代谢，不做数据迁移。

## 什么时候干的

2026-10-31。

## 后续优化方向

- 若仍见时效污染：可在 endOfTurn 加画像行级过滤（含「课表/明天/下周」等时效词的行降级为 memory），或评测集加「画像纯度」用例。
