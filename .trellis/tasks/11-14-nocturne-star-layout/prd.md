# 星图（nocturne）节点分布规则与「老记忆上星」成因排查

纯讨论/排查任务，无代码改动。起因：用户看 /brain 星图发现表盘有「今/一日/三日/七日/半月/一月」刻度，但实际星位分布无规律，且大量出现一周前的情景记忆。

## 结论：分布规则（源码口径）

数据链：`GET /api/state` → `Brain.graph()`（`allNotes()` 全量，**含 absorbed 退池存档条**）→ `buildMapVM` 过滤 `track==='world' || char===viewChar`（世界轨全部 + 当前人设 char 的自我轨）→ `quotaPick(notes, 150)` LOD 截断。

星位编码（`skins/nocturne.js` `_draw`）：

- **角度 = 年龄**：`day = note.ageDays = ⌊(now−createdAt)/86400e3⌋`（整数天，createdAt=记忆写入时刻；导入保留原始时间戳，巩固产物=巩固时刻而非事件时刻）。`ang(d) = -90° + √(d/32)·324°`，正上方=今，**顺时针渐远，√ 压缩**。
- **半径 = 类型 kind**：attitude 态度=132（内环）/ semantic 语义=206（中环）/ episodic 情景=280（外环），与时间无关。图例「由内而外 · 态度/语义/情景 · 顺时针渐远」。
- **表盘刻度不是筛选器**：「今/一日/三日/七日/半月/一月」六个标签用同一个 `ang(dd)` 摆位，是年龄标尺。
- **碰撞消解**：按 day 升序放置，与已放星欧氏距 <30px 则角度 +0.045 rad 重试，最多 60 次（最大偏移 ~155°）。环间距 74px>30px，跨环不碰撞。
- **LOD = `quotaPick`**：三 kind 按比例分名额（保底 floorN=min(6,⌊cap/kinds⌋)），组内按 `importance×retention` 降序——**完全不看时间**。
- 星等=importance（十字芒），透明度=retention。

## 实测数据（brain-data/walkthrough-2026-11-14.json，生产导出）

- notes 407 → visible 360（view=firefly）→ drawn 150。
- **absorbed（已被语义巩固吸收退池的存档条）237 条，占 58%；全部为 episodic。**
- quotaPick 结果：episodic 108 / semantic 31 / attitude 11；**drawn 中 84/150（56%）是 absorbed 存档**。
- drawn 年龄分布 0–14 天（数据最大 ~16 天）：day1-3 有 63 颗、day4-5 仅 4 颗、day6-14 铺开。episodic 环（周长 ~1759px）挤 108 星，平均间距 ~16px << 30px 碰撞阈值 → 碰撞推挤严重。
- 角度覆盖：d∈[0,16] → -90°~139° 弧段（约 64% 圆周），左上 ~131° 空白。

## 「一周前情景记忆」成因（按贡献排序）

1. **absorbed 存档条未被过滤也未被视觉区分**：`graph()` 返回含 `absorbed:true` 的条目，`buildMapVM`/三个皮肤均不消费该字段；巩固把 7–15 天前的 episodic 吸收成 semantic 后，原条按原 createdAt 继续上星图，与活记忆无异。外环「一周以上」区因此主要是幽灵存档。
2. **quotaPick 不看时间**：LOD 按 imp×ret 选星；活 episodic 仅 ~36 条，episodic 配额 108 必然大量吸入存档条；同时今天的低分记忆可能根本没画出来——画面年龄分布 ≠ 真实年龄分布。
3. **√ 压缩 + 碰撞推挤**：day0→1 差 57°、day25→28 几乎重合；密集环上星被沿角推最多 ~155°，精细年龄序被打乱。
4. 设计本身：时间只在角度、类型在半径，没有「越近越靠中心」的直觉映射。

## 附带发现（隐患，未触发）

`ang()` 在 d≈39.5 天扫满 360° 回到正上方；>39.5 天的记忆角度回绕、与新记忆重叠。当前数据最大 ~16 天，约再过 3–4 周会出现「老星跑到今天天顶」的错觉，届时需处理（如封顶/对数刻度/改螺旋）。

### 追加修复（同日，用户反馈「今天位置出现两周前数据」）

- **根因**：旧碰撞消解 `a += .045 × k<60` 单向无界推挤，密集格内星全部顶到 k=60 上限 → 最大偏移 **+154.7°**，day11–18 的语义/情景星被甩进 geo≈255–293°≈正上方「今夜」区（DOM 实测 dev 恰为 154.7°=60×0.045rad）。该缺陷在旧 √ 口径下同样存在，密度越大越严重。
- **修法**：`_place(m,r0,thr,taken)` 候选式落位——真实角 → 双向小角度（±~12°）→ 径向让位（±8/15 不出 kind 环带），取首个净空≥thr，全撞取净空最大者；活星 thr=30、星尘 thr=10。
- **验证**：headless 重测 max dev=**11.5°**，顶 ±30° 楔内只剩 day2–5 合法年轻星；274 tests+build 绿。
