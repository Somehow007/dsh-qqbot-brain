# 私密域隔离设计与评估

## Goal

给脑图记忆系统补一个「私密域」概念：私域会话产出的记忆/画像内容，只允许出现在私域会话的注入 prompt 中；公开群聊会话一律不可见。把「不泄漏」从靠模型自觉改成靠机制保证。

## 背景与证据（来自 11-07-host-brain-audit）

线上审计确认私密内容经三条路径可达多人群聊 prompt（群 17429483，turn 530/541/694-696 实证）：

1. **个人画像全量注入**：demo 在群发言时 `[画像]` 注入 u:demo 全量画像，含恋人关系与亲密约定——`assemble` 直接拼 `mergedUserProfile` 全文（src/brain/index.ts:197-202）。
2. **attitude 昵称保底**：`对demo：亲密节奏由我决定` 按 `content.includes(sp.nick)` 跨会话灌进【当前立场】——该过滤器完全没有会话/来源边界（index.ts:164-171）。
3. **跨群召回 xpool**：他会话的 semantic/attitude 按 actor openid/nick 匹配取 ≤2 条标 `[跨群]`（index.ts:172-195）——`demo：是鲸鱼娘的男朋友` 由此进群。

其余注入面已核实无泄漏：主检索池按 sessionId+GLOBAL 过滤（retrieval.ts:125）、digest/emotion 按会话隔离、persona 全局只读。bot 群发言目前干净，但机制上私密语境三路可达，一次失口即社死。

## Requirements

- R1 私域标记：会话可被打上「私域」标签（具名 domain，如 `demo`），同名 domain 的多个会话共享一个信任域；标记持久化、可在脑图页修改。
- R2 记忆域派生：note 生效作用域读侧派生（`n.private` 手动覆盖 ?? 来源会话域），私域产出只在同域注入可见；公开会话写出的 note 默认公开（保持现状）；标域对存量即时生效，零回填。
- R3 注入单点过滤：`assemble` 的可见池统一按「note 私钥 == 目标会话私钥」过滤，使 topK、attitude 保底、跨群召回、reinforce 四处同口径生效。
- R4 画像分段私域：u:/sess: 画像文本内以 `〔私〕` 句首标记的句子属私域内容，注入非私域会话时剔除该句；蒸馏/审核/重生成 prompt 都要会写、会保留该标记。
- R5 合并边界：判重/合并不得跨生效作用域（同域才参与互判）；`mergeNotes` 结果取更严覆盖。
- R6 手动降级/密化通道：脑图页/API 可对单条 note 改私域归属（把私域里的良性事实放行到公开，或把公开会话里的敏感条收回本会话）；GLOBAL(manual) 域 note 也可标私域。
- R7 可验证：提供针对导出数据的干跑验证——以 demo 为发言人在群会话跑 assemble，断言输出不含私域关键词。

## Acceptance Criteria

- [ ] 标记 domain=demo 的会话产出的 note，在公开会话 assemble 的 memoryLines/attitudeLines 中零出现（topK/保底/跨群三路均无）。
- [ ] u:demo 画像中含 `〔私〕` 的句子不出现在公开会话注入；在 demo 私域会话注入中完整保留。
- [ ] 私域 note 的 hits/strength 不再因公开会话检索而被强化。
- [ ] 同义事实公开/私域各存一条互不干扰；跨域不被 findNearDup/sweepNearDups 合并。
- [ ] 存量数据迁移后：恋人线相关 note/attitude 对群会话不可见；u:demo 画像私密段已标 `〔私〕`。
- [ ] 测试覆盖：domain 标记、继承、三路过滤、画像剥句、合并边界、导入导出兼容。

## Key Decisions

- **隔离口径 = 硬隔离**（用户确认 2026-11-07）：私域 note 与画像私段在公开会话 prompt 中完全不存在，不注入「知道但不能说」的降级提示行——提示行本身就是元信息泄漏。代价已接受：demo 私聊里的良性事实群里召回不到，由 u: 画像公开段承担稳定事实。
- **域 = 具名信任域，非 boolean**：`domain=demo` 覆盖 demo 私聊 + 恋人线群（同一受众互通）；未来第二个人的私域换新 domain 名即天然隔离。
- **域判定 = 人工标记，存 store+op**：不做参与者数自动推导（「单人群」随第二人发言翻转有泄漏窗口）；脑图页即时改、免 redeploy。
- **画像私段 = 行内 `〔私〕` 标记**：不拆 privateText 字段，审核/合并/重生成全链路零分叉；剥句在注入侧确定性执行，不依赖模型自觉。
- **私域会话名单**（待部署时确认执行）：`dbf7162a`、`1fbd1c03` + 死会话 `832f1a89`/`f7485370`/`96fe6849`/`a7c9ce4f`/`e6b717d7` → `domain=demo`。

## Out of Scope

- sess:17429483 群画像「单人特征误写为群画像」的归因修正（P0-2，另行处理；`〔私〕` 机制不解归因错误）。
- actor 归一化 / 真名注册表（P1-3/P1-8）、merge 不动 createdAt（P1-4）等审计其余项。
- 按「人」粒度的域成员资格（本期域=会话集合的信任域；第二个私域用户出现时再细化，域模型已预留具名 domain）。
