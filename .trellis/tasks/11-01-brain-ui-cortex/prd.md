# 脑图前端重构：鲸脑皮层（概念①）

## Goal

以已存档的概念 ① `mockup-mind-cortex.html` 为视觉与交互基准，重构 `/brain` 页面（`dsh-qqbot-brain/src/server/page.html`）：用"大脑侧剖面 + 脑区分层 + 神经信号"表达 记忆 ↔ 记忆 ↔ 情绪 ↔ 人格 的关系，带出大肥鱼形象与语气；现有产品功能零回归、**不改后端**。

概念存档：`.trellis/tasks/archive/2026-11/11-01-brain-concept-redesign/`（提交 `aaa9c41`、`fda6e82`）。②③ 留作后续个性化皮肤。

## Background（仓库证据）

- 页面为单文件零依赖 HTML/CSS/JS，`npm run build` 复制到 `dist/server/page.html`；约束见 `.trellis/spec/frontend/quality-guidelines.md`（API 文本一律 `textContent`、详情不截断 `content`、记忆库是溢出兜底、15s 刷新不覆盖人设草稿、备份走 `/api/export`）。
- 工作区有**未提交**的上一轮 B 版实现（任务 `11-01-brain-ui-abyss`，`page.html` +655/−399）。可复用：`computeRelations()`/`relationWhy()`（话题/会话/发言人，含测试，`page.html:407-423`）、检查器 `panel()`（`page.html:679`）、记忆库/会话/画像/人设/操作页签、内联立绘 `PERSONA_IMG`/`PERSONA_BANNER`（`page.html:371-372`）。将被替换：力导向模拟 `SIM`（`page.html:575-639`）、粒子 canvas（`page.html:979`）、平移缩放（`page.html:955`）。
- `/api/state`（`Brain.graph()`，`src/brain/index.ts:489-530`）：
  - 记忆：`kind`、`content`、`importance`、`actor`、`sessionId`、`createdAt`、`strength`、`retention`、`hits`、`fading`；**无记忆级情绪字段**。
  - 情绪：只有当前 PAD `{v,a,d,label}`。历史在 `/api/ops` 的 `op:'emotion'`（含 `sessionId`、`state`、`t`），由同一次蒸馏在写入记忆后紧接着写入（`src/brain/index.ts:271-272`）；日志上限 500 条（`store.ts:124`），页面当前只取 120（`page.html:467`）。
  - 人格：只读全文；默认人设 `src/setup/whale-gentle.md` 以 `## ` 分节（身份与底色 / 性格怎么演 / 群聊与称呼 / 说话风格 / …），无结构化特质。

## Decisions

- D1（用户确认 2026-11-01）：情绪层、人格层的连线**纯前端推断**，不改后端，界面明确标注"推断"。
  - 情绪：按 PAD 把每次 `emotion` 记录归入 5 个固定情绪桶；记忆取**同会话、`createdAt` 之后最近（≤10 分钟）**的一条情绪记录作为"形成时情绪"。匹配不到 → 不连线。
  - 人格：把当前人设按 `## ` 小节拆成特质节点（≤6）；记忆与小节正文做 n-gram 重合打分，超过阈值才连"塑造/体现"。
- D2（推荐，随计划一并确认）：以当前未提交的 B 版工作区为起点重构，复用其关系推断与业务逻辑，删除力导向/粒子/平移缩放/拖拽；本任务开工后，`11-01-brain-ui-abyss` 以"被本任务取代"归档。
- D3（推荐）：节点固定布局（预计算脑区槽位），动效只有星点闪烁与信号脉冲。

## Requirements

- R1 主视图：大脑侧剖面（大脑/小脑/脑干轮廓 + 沟回 + 区域柔光 + 星点神经元 + 外侧引线标注），视觉对齐概念 ①。
- R2 脑区分层：海马体=情景、新皮层=语义、顶叶=态度、杏仁核=情绪、前额叶=人格。记忆按 `retention` 降序填入本脑区槽位；每区有容量上限（总量 ≤30），溢出显示 "+N 条" 并跳转记忆库（已按该类型筛选）。
- R3 节点形状：人格=六边形、情绪=实心光点（大小=该桶记忆数）、记忆=空心环（半径=重要度，`fading` 时虚线变暗）。标签用短预览（复用 `previewText`/`nodeLabel`），全文只在检查器。
- R4 关联边：记忆↔记忆沿用 `computeRelations()` 三类（虚线），记忆→情绪、记忆→人格（D1）默认隐藏，选中才显示；当前情绪桶有心跳环。
- R5 交互：点选节点 → 无关节点淡出、关联边点亮、脉冲两跳扩散；点空白/Esc/复位按钮清除；节点可 Tab 聚焦、Enter 选中。
- R6 检查器（右栏）：Smile 横幅 + 大肥鱼气泡（按选中对象切换文案，复用 `companionLine` 思路）；选中记忆时显示类型、全文、来源/时间/保持率、按 记忆/情绪/人格 分组的关联列表（含推断理由，可点击跳转），并保留现有编辑/强化/删除；未选中时显示人格光谱 + 情绪读数（当前 PAD label 与近期曲线）。
- R7 检索：`/query` 命中的记忆节点高亮并沿命中边发脉冲，结果列表可点进检查器。
- R8 动效：信号脉冲开关（localStorage 记忆），`prefers-reduced-motion` 默认关；`document.hidden` 时不发脉冲；空闲时无持续重绘。
- R9 主视图下方现有页签（记忆库 / 会话 / 画像 / 人设 / 操作 / 备份）功能不变，视觉统一为 ① 的深海色板。
- R10 空数据、单条记忆、无人设、无情绪记录、长文本、窄屏（≤900px 侧栏下沉）都有合理展示。

## Acceptance Criteria

- AC1（R1-R3）真实数据下截图与概念 ① 结构一致：脑轮廓、五个脑区标注、三种节点形状；30 条记忆时标签不互相覆盖。
- AC2（R4-R5）点选记忆：其记忆关联、情绪、人格连线点亮且检查器列出同样的关联与理由；点选情绪/人格节点能反查其记忆；空白点击复位。
- AC3（D1）情绪匹配与人格小节匹配有单元测试（命中、超时不匹配、跨会话不匹配、无 `##` 人设、阈值以下不连）。
- AC4（R6-R7、R9）CRUD、强化、检索、人设草稿保护、导入导出、15s 刷新均无回归（jsdom 冒烟 + 手动）。
- AC5（R8、R10）reduced-motion 下无动画；空库/无人设/无情绪记录页面不报错。
- AC6 `npm test`、`npm run typecheck`、`npm run build` 全绿，`dist/server/page.html` 同步。

## Out of Scope

- 概念 ②③ 皮肤与皮肤切换。
- 前端框架或第三方依赖。
- 节点拖拽、画布平移缩放（固定布局下不需要）。

## Resolution（2026-11-01）

### 遇到了什么问题

- 原 /brain 脑图是自由物理散点 + 浅色标本风，用户多轮反馈"杂而乱、不像类脑、没美感、数量一多就爆炸"，要求按概念 ①（鲸脑皮层侧剖面）做真结构重构而非贴皮。
- 后端无关系边/情绪历史/结构化人格字段，类脑三层关联只能在前端推断。
- 迭代中陆续暴露：节点亮环像"靶心"与脑底色脱节、立绘过曝且带文字、海马体 "+N" 标签压图例、窄屏立绘拉伸/图表过大/搜索框压标签。

### 怎么解决的

- **结构**：整页按概念 ① 重写为大脑侧剖面——大脑/小脑/脑干轮廓 + 沟回 + 区域柔光 + 引线标注；脑区分层（前额叶=人格六边形、杏仁核=情绪桶、新皮层=语义、顶叶=态度、海马体=情景）。固定槽位 `layoutSlots()` 中心外扩贪心排布，标签盒不重叠不出脑区；每区 CAP 上限，溢出 "+N ↗" 跳记忆库并预筛选类型。
- **推断（纯前端，后端零改动）**：`emotionOps/matchEmotion` 从 `/ops?limit=500` 取同会话 ±10 分钟情绪记录映射到五个固定桶；`personaFacets/matchFacet` 按 `##` 小节拆人格、共享 bigram ≥阈值才连边；记忆↔记忆沿用 `computeRelations()`（相似话题/同一会话/同一发言人）。页面明示"全部为推断，非因果"。
- **交互**：点选→无关淡出+邻边点亮+脉冲两跳扩散；检查器分组列出 记忆/情绪/人格 关联及理由，可跳转；检索命中高亮+悬浮结果列表；Esc/空白/复位清除；15s 刷新保持选中与未存草稿。
- **动效**：两层粒子（脑内 64 + 脑外 14）+ 节点原位微漂（±2.6，边同帧跟随）+ 信号脉冲，统一由「漂浮」开关控制（`brain-particles`），reduced-motion 默认关、后台标签页暂停。
- **观感**：节点从霓虹靶心改为类型色 10% 淡晕细胞球（弱化环、强化芯）；节点尺寸方案 A（-35%）；立绘换用户提供形象、裁掉文字、深蓝渐变压色；修复窄屏立绘拉伸、图表过宽、搜索框遮挡、溢出标签压图例。
- **保留**：全部页签功能（记忆库/会话/画像/人设/操作/备份）、CRUD、强化、导入导出、token 透传、单文件零依赖。

### Key Decisions

1. 情绪/人格关联前端推断并明示"非因果"——后端 schema 不动；推断覆盖不足时另开任务而非放宽阈值。
2. 固定槽位布局取代物理模拟——"活的"感觉用微漂+脉冲表达，不用游离布局。
3. 节点视觉迭代三轮（霓虹环→淡晕细胞球→方案 A 缩小 35%），先出等比概念页（mockup-node-icons.html）让用户定稿再实施。
4. 立绘内嵌 base64（35KB JPEG）而非静态路由——守"零后端改动"边界。

### 验证结论

- `npm test` 82/82（含 6 个推断/槽位新用例）、typecheck、build 全过；`dist/server/page.html` 已同步。
- jsdom 冒烟 33 项 + 空库 5 项全过：节点/边/桶数、选中-淡出-亮边-关联列表、检索、编辑器、刷新保持选中、粒子层开关持久化、漂移幅度与边跟随。
- headless Chrome 截图走查：总览/选中记忆/选中情绪/选中人格/检索/空库 ×1440/1280/900/640/420，无横向滚动条，无控制台报错，61fps。
- 已知限制：旧记忆无邻近情绪 op 则无情绪连线；人设与记忆措辞重叠少时人格边稀疏（设计内预期）。

### 后续优化方向

- 后端若做记忆级情绪/结构化特质，可把推断换成真实字段（独立任务）。
- 概念 ②③（咖啡馆/回廊）可做皮肤切换；atlas A/B/C 个性化方案留档。
- 真实数据下如情景类溢出严重，可调 `CAP` 或缩短 `mapLabel`。
