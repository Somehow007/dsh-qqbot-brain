# 实施顺序

1. 固定页面改动边界：保存 `git diff -- dsh-qqbot-brain/src/server/page.html` 基线；核对现有 UI 样机、状态及交互入口。
2. 整理统一的概览摘要/详情查看路径，优先让记忆卡片、检索命中和库表可识别并可定位完整文本；保持原始数据与 API 不变。
3. 调整脑图密度、节点标签、选中反馈和整页排版；兼顾窄屏和长文本；不覆盖已有情绪会话展示。
4. 针对长文本、同前缀、空数据与较多记忆补充适合当前无框架页面的验证；运行 `npm test`、`npm run typecheck`、`npm run build`（在 `dsh-qqbot-brain/`）。
5. 逐项核对 PRD 验收标准、已有未提交改动及 `git diff`；如能本地起预览，检查桌面和移动宽度的实际观感。

## Risk / Rollback

主要风险是单文件页面的 DOM 更新与刷新交互相互影响；只提交该页面及明确新增的页面测试，保留原有未提交改动。若展示导致图过密，优先减少图上直接文字而保留卡片/库表到全文详情的通路，不更改后端字段或裁剪原文。
