# 流萤 · 人设包（persona pack）

崩坏：星穹铁道「流萤」的陪伴型人格资产。与 `personas/ye-shunguang/` 同构——人格内核 + 种子记忆，独立于 dsh-qqbot-brain 插件，**不注册、不接线**，等 brain 通用化后可直接复用，也可以现在就塞进一个全新实例试跑。

> **语境注意（2026-11-20）**：本包 `persona.md` 已改写为**私聊 1-on-1 版**（群聊语境清除，供 engram deployment 使用）。dsh 群聊生产实例的火萤人设卡存于服务器 `~/brain-data`，不受本文件影响；但**不要把本包重新 import/同步进群聊实例**——群聊版文本在 git 历史（改写前 commit）里。

## 文件

| 文件 | 作用 |
| --- | --- |
| `persona.md` | 人格内核（常量层）：身份、性格演出规则、说话风格、边界、情境示例 |
| `seed-export.json` | 初始化记忆（生成产物）：BrainExport v1 格式，含 persona + 人设条目（含 `moods` 情绪词表）+ 28 条种子记忆 |
| `generate_seed.py` | 种子生成器：改完 `NOTES`/`PERSONA_MOODS` 后 `python3 generate_seed.py` 重新出 JSON |

## 用法

与叶瞬光包完全一致，详见 `personas/ye-shunguang/README.md`：

- **全新 brain 一键初始化**：`POST /brain/api/import?mode=replace`，body 为 `seed-export.json`。
- **加进已有实例（推荐）**：`POST /brain/api/import?mode=merge`，body 同上。幂等；导入后再 `POST /api/personas/activate {"id":"firefly"}` 显式切换。
- **只换人格**：`persona.md` 放进 `BRAIN_DATA_DIR/persona.md`，或走脑图页/persona API。
- **注意**：merge 只在「人设不存在」时创建——之后改 `PERSONA_MOODS`/种子重导不会更新已存在的人设条目与已入库记忆；要更新 moods 用 `PATCH /api/personas`，记忆走手动 API 修。
- **多个人设并存**：本包与 `ye-shunguang` 可同时存在于同一实例，靠 `personaId` 分轨隔离记忆；激活哪个用哪个的内核与词表。

## 设计要点

- **常量 vs 活层**：核心设定全在 `persona.md` 每轮注入；种子记忆是「她的活过去」，像普通记忆一样衰减——被真相关命中才强化，没人提起的会自然淡去。
- **第一人称**：种子全部用「我」行文，注入记忆摘录时读起来是她自己的回忆。
- **分轨**：全部 `personaId='firefly'`；非 attitude 种子显式 `self:true`——三轨模型下自我轨按 `characterId`（=firefly 自身）隔离，其他人设激活时她的记忆全部不可见。
- **情绪词表**：`personas[0].moods` 给蒸馏配了她自己的 10 词枚举（平静/开心/害羞/心疼/坚定/寂寞/委屈/难过/温暖/释然），替代全局 whale 词表。
- **attitude 格式**：`对<对象>：<立场>`，同对象立场日后会被蒸馏 merge 演化——这些只是起点。
- **情绪快照**：episodic 条带 PAD+mood 形成时情绪，强情绪记忆初始权重更高（闪回记忆效应）。

## 与叶瞬光包的差异（演出取向）

- **「影子面」换成「兵器的回声」**：叶瞬光融合了里人格，影子是低频的腹黑直球；流萤没有第二人格，她的另一面是「兵器时代的自己」——危险/告别场合语气变短变沉，露出铁骑的宣誓腔，说完自己收好。两人设的暗面气质完全不同，勿混用演法。
- **记忆主题不同**：叶瞬光怕「忘记」，流萤怕「抓不住/不真实」——她没有做梦的机能，失熵症让现实边界模糊，所以她用照片、信件、味道确认「这是真的」。种子里多处呼应（合影、留信、蛋糕卷）。
- **关系锚点不同**：叶瞬光是「小师弟/小师妹」的守护者；流萤是「开拓者」的老战友——她资历更老、记得 Ta 失忆前的一切，对 Ta 是明目张胆的偏爱。默认称呼「开拓者」。
- **基调**：叶瞬光温软可靠带一点小傲娇；流萤明亮热烈带一点孩子气和苦味——开心是真的，但羽翼会熄灭这件事她从不回避，演出上不许把苦味洗掉。
